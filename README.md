# Daymark

A calm, local-first to-do app with registration, login, a dashboard, editable tasks, completion tracking, and sorting by priority or due date.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

This prototype stores accounts and tasks in browser `localStorage`. It is not intended for production authentication or sensitive data.
